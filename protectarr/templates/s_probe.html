Content Probe - advanced, opt-in

Everything else Protectarr does reads the torrent's file list, which is why it costs no bandwidth and answers in seconds. That cannot catch a payload wearing a real .mkv or .mp4 extension, because nothing in the metadata is lying. The probe downloads the first piece of one file - a few MB out of many GB - and checks the bytes really are the format the name claims.

It only runs on torrents the fast checks had nothing to say about, and only on torrents your reaping rules would let Protectarr act on. A file that cannot be read, cannot be recognised, or runs out of budget produces no finding - never a removal.

Path Mapping

Protectarr has to be able to read the files qBittorrent is writing, so mount the download directory into Protectarr as well. If it lands at the same path qBittorrent reports, you are done and need nothing here.

Add a mapping only when the two see the same folder at different paths: it translates one into the other. Note the path to match is the one qBittorrent reports, which on a NAS is often not the host path - a share at /volume2/Media/torrents may be /Media/torrents to qBittorrent. Budget

Reading a piece the torrent already happens to have is free, and always allowed. Fetching one on purpose means briefly raising one file's priority above the torrent's other files and turning on sequential download - always restored afterwards, and restored on the next start if Protectarr is killed mid-probe. Nothing is switched off, so the torrent's size and progress never change. These limits bound what that is allowed to cost.

Steering only influences which piece qBittorrent picks next; it cannot recall one already in flight. On a torrent crawling from one seed the piece may be twenty minutes away, so the budget is better not spent. Fakes are heavily seeded by design - the attacker wants downloads - so the torrents that matter are the ones this works best on.

A scan that has a fake queued for removal reaps it first and probes on the next pass, so probing never delays a removal the fast checks already decided on.

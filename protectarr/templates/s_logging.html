Logging

Debug records every step of every scan: which torrents were inspected or skipped and why, what each detector saw, how the profile judged it, and the air-date decision behind a requeue. Useful while something is behaving oddly, noisy the rest of the time.

The file rolls over at midnight, gets renamed with the date and gzipped, and is deleted once it is older than the retention above. Credentials are redacted from every log, so a file here is safe to attach to a GitHub issue.

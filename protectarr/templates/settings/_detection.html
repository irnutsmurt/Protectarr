Monitored Extensions

A download is flagged for removal when its file list contains any of these. Separate with commas or newlines; a leading dot is added if you leave it off.

Recommended. Much faster on large libraries, and a fake that has already finished is past the point of catching.

How this works

Public trackers seed video-sized decoys named like Show.S01E01.1080p….exe. qBittorrent learns a torrent's file list from its metadata within seconds of adding it, long before any content arrives, so an extension match costs no bandwidth and answers almost immediately.

Skipping finished torrents leaves Sonarr/Radarr's own "Fail Downloads" as the backstop for anything that completes between two scans.

Lure Filenames

Matched as substrings of the filename. Separate with commas or newlines.

How this works

Flags a download when a text-like companion file (readme / nfo / url) is named like a fake's instructions, for example password.txt or how to download.html.

Only those note-style files are checked, which is what stops a false positive: a real release titled Password.mkv is never flagged, because a video file is not a note.

Archive Detection - advanced, opt-in {% if summaries.archive %}{{ summaries.archive.text }}{% endif %}

{#- Prominent and outside the disclosure on purpose. This is the one detector that can act on a legitimate release, and an operator switching it on has to meet that sentence before the checkbox. -#}

Flags a download that contains only archives (RAR/ZIP/…) with no real media file. Legit releases are sometimes packed in RARs - especially on private trackers - so this is off by default and only applies to the indexers you list below. Leave the list empty to disable.

Loading indexers from your apps…

With none selected this rule never fires, whatever the checkbox above says.

How this works

Only *arr-tracked downloads are eligible, because that is where the indexer name comes from and where "what counts as media" is knowable. Hand-added torrents are never touched by this rule.

A torrent is only archives-only if Protectarr finds no media file at all in the list. One real video alongside the RARs and the rule does not fire.

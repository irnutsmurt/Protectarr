File Detection

Monitored Extensions

A download is flagged for removal when its file list contains any of these extensions. Public trackers seed video-sized decoys named like Show.S01E01.1080p….exe.

Lure Filenames

Flag a download when a text-like companion file (readme / nfo / url) is named like a fake's instructions - e.g. password.txt or how to download.html. Only these note-style files are checked, so a real release titled Password.mkv is never flagged.

Archive Detection - advanced, opt-in

Flags a download that contains only archives (RAR/ZIP/…) with no real media file. Legit releases are sometimes packed in RARs - especially on private trackers - so this is off by default and only applies to the indexers you list below. Leave the list empty to disable.

Loading indexers from your apps…

Only *arr-tracked downloads are eligible (that's where the indexer name comes from). Hand-added torrents are never touched by this rule.

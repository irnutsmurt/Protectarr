Peer IP Blocklist {% if summaries.blocklist %}{{ summaries.blocklist.text }}{% endif %}

Downloads a peer blocklist and points qBittorrent's IP filter at it.

Defaults to Naunter/BT_BlockLists. Any gzipped p2p-format list works.

As qBittorrent sees it, not as Protectarr does.

The list changes slowly; daily is plenty.

With this off the file is still downloaded, but qBittorrent is never told about it.

How this works

Protectarr downloads the list and writes it to the path above. qBittorrent is the process that reads it, so the path has to be one qBittorrent can open. In Docker that means a volume mounted into both containers, at the same path in both.

This is a bulk filter of addresses other people have reported, applied before a connection is made. It is unrelated to the swarm observations Protectarr records on its own, and it never bans anything by itself.

{#- Not part of the unsaved-changes controls. Refreshing the list is useful when nothing has been edited, so it has to stay reachable on a clean card. Clicking it with edits pending saves them first, which is what it has always done. -#}
